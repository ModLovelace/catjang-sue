## 🌟 ¿Qué es Catjang-Sue?

**Catjang-Sue** es un fork comunitario de escritorio evolucionado a partir del prototipo original de **jan (nerfspeed)** bajo licencia `CC BY-NC 4.0`. 

Transformamos un proyecto archivado en un **ecosistema de escritorio multiplataforma moderno, de alto rendimiento y reactivo en tiempo real a agentes de Inteligencia Artificial**. No es solo un adorno visual: es un compañero interactivo para desarrolladores que refleja el estado de tu entorno de trabajo y el ciclo de vida de tus IAs.

---

## 🚀 Hitos de Ingeniería & Características Clave

### 1. 🤖 Conexión en Tiempo Real con 5 Agentes de IA
Catjang-Sue se conecta mediante hooks de ciclo de vida y monitores de logs a las herramientas de IA más utilizadas por desarrolladores:
* **Gemini CLI / Antigravity**
* **Claude Code**
* **Cursor**
* **OpenAI Codex**
* **Kiro**

#### Expresiones Reactivas Dinámicas:
- 🧠 **Pensando:** Tu mascota entra en estado de máxima concentración y análisis.
- ⚡ **Ejecutando herramientas:** Tecleo ultra acelerado con emisión de humo térmico por velocidad sostenida.
- ⚠️ **Esperando confirmación:** Estado de alerta y atención visual cuando la IA requiere tu aprobación humana.
- 🎉 **Tarea completada con éxito:** Salto alegre animado y campanilla reactiva.

---

### 2. 🐾 Catálogo Canónico de 6 Mascotas (8 Animaciones SVG por Especie)
Cada especie cuenta con assets vectoriales SVG optimizados y físicas dedicadas:

| Mascota | Especie | Personalidad & Animación Distintiva |
| :---: | :--- | :--- |
| **Catjang** 🐱 | Gatito Clásico | Tecleo vertiginoso, cansancio progresivo y humo térmico. |
| **Toto** 🐶 | Schnauzer | Cejas expresivas de alta fidelidad y ladrido sutil interactivo. |
| **Chisi** 🐩 | Caniche Toy | Pelaje blanco esponjoso y animaciones suaves de descanso. |
| **Milo** 🐕 | Mestizo | Entusiasta, cola enérgica y expresiones dinámicas de acompañamiento. |
| **Musubi** 🐱 | Gato Atigrado | Texturas rayadas detalladas y ronroneo reactivo al puntero. |
| **Chuño** 🐕🇵🇪 | **Perro sin Pelo del Perú (Viringo)** | **Homenaje cultural:** Cresta cobriza, manchas térmicas en la piel, enrojecimiento progresivo por KPS y **teclados 3D hundibles de 4px**. |

---

### 3. 🎮 Físicas Elásticas & Sensórica Interactiva
* **Arrastre Pendular Físico:** Al levantar a tu mascota con el ratón, reacciona con un balanceo elástico realista ($\pm 16^\circ$ en patas, $\pm 22^\circ$ en cola).
* **Caricias Deliberadas:** Algoritmo con retardo intencional (~1.4s) para diferenciar clics accidentales de caricias voluntarias.
* **Audio Reactivo Sintetizado:** Cada especie emite sonidos característicos en eventos clave sin cargar archivos pesados.
* **Shaders SVG Especiales:** Uso de filtros `<feMorphology>` para eliminar bordes y artefactos negros en ventanas transparentes de Chromium sobre Windows y Linux.

---

### 4. 🧪 Calidad de Software, Rendimiento & QA Metódico
Diseñado bajo el principio de ingeniería: **«Pausar, Diagnosticar y Corregir»**.

* 🟢 **54 / 54 Pruebas de Regresión Automatizadas:** Validación rigurosa de ciclo de vida, transparencia de ventana y comunicación entre procesos.
* ⚡ **Consumo de Recursos Ultraligero:** Mantiene un consumo de CPU de apenas **0.5% – 0.95%** en segundo plano, sin picos de GPU ni interferir con la compilación de tus proyectos.
* 📋 Documentación de testing: Consulta la [`TESTING_AND_QA_GUIDE.md`](docs/TESTING_AND_QA_GUIDE.md).

## 🐧 Instalación en Linux (Wayland / X11)

Para distribuciones como Ubuntu, Debian, Fedora o Arch:

```bash
# 1. Clonar el repositorio
git clone https://github.com/ModLovelace/catjang-sue.git
cd catjang-sue

# 2. Cambiar a la rama de Linux/Wayland optimizada
git checkout community/linux-wayland

# 3. Instalar dependencias
npm install

# 4. Iniciar en modo desarrollo
npm start
```

## 🛠️ Desarrollo Local & Compilación

Si deseas contribuir o compilar los instaladores por tu cuenta:

```bash
# Instalar dependencias
npm install

# Iniciar la aplicación
npm start

# Compilar instalador para Windows
npm run dist:win

# Compilar instalador universal para macOS (.dmg)
npm run dist:mac
```
